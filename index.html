SVG Bounding Rectangle

A tiny offline tool for Fusion: load an SVG, automatically create an axis-aligned vector rectangle around its vector geometry, and download the modified SVG.

Drop an SVG hereor click to choose a file · Nothing is uploaded

About visual strokes: The rectangle follows the exact outer limits of the SVG path geometry, not its stroke thickness. If a stroke appears to extend beyond the rectangle, this is normal: SVG strokes are drawn across the path. The geometric bounding rectangle is still correct for scaling in Fusion.

Coordinates in original SVG user units
Supports vector SVG shapes, including curves and transformed groups.

For Fusion: Insert → Insert SVG. The added rectangle is a separate closed vector element (id="fusion-bounding-rectangle") with no optional margin. Visible stroke thickness is deliberately excluded from the measurement. The original artwork and its appearance are preserved for ordinary vector SVGs. Complex sharp miter joins, clipping, masks, filters, external content, raster-image transparency or unusual nested viewports should be checked manually.
